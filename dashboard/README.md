# LibreSpec Dashboard

This is the Next.js frontend dashboard for the LibreSpec ecosystem. It serves as a Forensic Analytics Command Center to monitor real-time biochemical spectral analysis and cryptographic verification for edge-computed telemetry.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Features

- Real-Time Operations: Monitor incoming spectral telemetry.
- Global Telemetry Map: View geographic acquisition locations.
- Cryptographic Integrity: Verify immutable data seals.
- Spectral Kinetics: Interactive charts to visualize baseline and plateau vectors.

## Technologies Used

- Next.js (App Router)
- React
- Tailwind CSS
- Recharts
- Leaflet (React-Leaflet)
- Lucide React
